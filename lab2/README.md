## 🚀 Как компилировать и запускать

### Задача 1 (НОД)
```bash
gcc task1.c -o task1 && ./task1
```

### Задача 2 (НОК)
```bash
gcc task2.c -o task2 && ./task2
```

### Задачи 3, 4, 5 (Определение простого числа разными циклами)
```bash
gcc task3.c -o task3 && ./task3
gcc task4.c -o task4 && ./task4
gcc task5.c -o task5 && ./task5
```

## 📑 Анализ фрагментов кода
1. **Алгоритм 1:** Ищет Наибольший Общий Делитель (НОД) двух чисел перебором вниз от `n1`.
2. **Алгоритм 2:** Вычисляет Наименьшее Общее Кратное (НОК) двух чисел, увеличивая счётчик от `a`.
3. **Алгоритмы 3-5:** Различные циклические структуры для проверки числа на то, является ли оно простым (возвращают 1) или составным (возвращают 0).
