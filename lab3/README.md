```bash

```

## 📑 Описание алгоритмов
* **Задача 1:** Исполняет вложенный цикл размерностью $N \times N$, выводя увеличивающийся на единицу счетчик `count`.
* **Задача 2:** Использует три вложенных цикла внутри основного: первый для выравнивания пробелами, второй для убывающего вывода алфавита, третий для возрастающего.
