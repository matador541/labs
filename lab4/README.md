Решения практического задания по битовым операциям (Вариант 5).

## 🚀 Как компилировать и запускать

### Задача 1 (Циклический сдвиг влево)
```bash
gcc task1.c -o task1 && ./task1
```

### Задача 2 (Подсчет нулей с 3 по 13 бит)
```bash
gcc task2.c -o task2 && ./task2
```

## 📑 Описание функций
* **Задача 1:** Функция `cyclic_shift_left` выполняет побитовый сдвиг числа влево с заполнением освободившихся разрядов битами, вытесненными за левую границу разрядной сетки.
* **Задача 2:** Функция `count_zeros_in_range` использует цикл и битовую маску для поочередной изоляции каждого бита в диапазоне с 3 по 13 позиции и инкрементирует счетчик при обнаружении нуля.
