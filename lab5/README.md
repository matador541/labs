## 📑 Краткий анализ алгоритмов
* **Задача 1:** Демонстрирует базовые алгоритмы прохода по одномерному массиву: вычисление суммы, среднего значения, а также поиск экстремумов (минимума/максимума) и их индексов.
* **Задача 2:** Моделирует обработку комплексных IQ-компонент, высчитывая общую физическую энергию сигнала на основе суммы квадратов амплитуд.
* **Задача 3 (Вариант А2):** Реализует алгоритм программной детекции движения по побитовым разностям уровней RSSI соседних замеров, выделяя временные отрезки активности.
