Репозиторий содержит универсальное решение СЛАУ методом Крамера для любой размерности $N \times N$ (Оценка 5).

## 🚀 Как компилировать и запускать

```bash
gcc task1.c -o task1 -lm && ./task1
```

## 📑 Описание алгоритма
Программа динамически выделяет память под двумерные массивы. Вычисление определителей матриц произвольного порядка $N \times N$ реализовано через рекурсивное разложение по строке (вычисление миноров). Нахождение неизвестных векторов осуществляется по правилу Крамера путем последовательной подстановки вектора свободных членов в столбцы исходной матрицы.
