## 📑 Описание используемых функций
* **Задача 1:** Использует `strchr` для поиска разделителя `@`, `strncpy` для вырезания имени пользователя и стандартный метод смещения указателя для копирования домена.
* **Задача 2:** Применяет макросы `isspace` и `tolower` для нормализации текста с последующим встречным перебором индексов символов для верификации симметрии.
* **Задача 3:** Реализует последовательный разбор строки на токены функцией `strtok` по символу пробела и проверяет нулевой индекс каждого слова на равенство префиксу `#`.
